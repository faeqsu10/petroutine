## 설계 원칙 (모든 플로우 공통)

| 원칙 | 설명 |
|------|------|
| **최소 입력** | 모든 핵심 행동은 3탭 이내 완료 |
| **운영 중심** | "지금 뭘 하면 되지?"에 즉시 답하는 구조 |
| **긴급도 시각화** | 빨강(지남) / 노랑(곧) / 초록(여유) |
| **반자동 루프** | 최초 1회 설정 이후 알림-완료-다음일정 자동 반복 |
| **모바일 퍼스트** | 한 손 조작, 하단 네비게이션 기준 |

## 1. 온보딩 플로우

### 시나리오
> 처음 앱을 설치한 보호자가 회원가입 후 반려동물을 등록하고,
> 기본 케어 항목과 주기를 설정하여 홈 대시보드에 도착하는 과정

### 플로우 다이어그램

```
┌─────────────────────────────────────────────────────────────────┐
│                        온보딩 플로우                              │
└─────────────────────────────────────────────────────────────────┘

  [앱 첫 실행]
       │
       ▼
  ┌──────────────┐
  │  스플래시     │  앱 로고 + "기억에 의존하지 않는
  │  스크린       │   반려동물 관리" 태그라인
  └──────┬───────┘
         │
         ▼
  ┌──────────────┐     ┌───────────────────────┐
  │  웰컴 화면    │     │  스와이프 온보딩 (3장)   │
  │  (가치 소개)  │────▶│  1. "알림 받고 버튼 하나" │
  │              │     │  2. "주기 자동 관리"     │
  └──────┬───────┘     │  3. "지출도 한눈에"      │
         │             └───────────┬───────────┘
         │                         │
         ▼                         ▼
  ┌──────────────────────────────────┐
  │         회원가입 / 로그인          │
  │  ┌────────────────────────────┐  │
  │  │  [카카오로 시작하기]  ← 추천  │  │
  │  │  [Google로 시작하기]        │  │
  │  │  [Apple로 시작하기]         │  │
  │  │  ─────────────────────     │  │
  │  │  [이메일로 시작하기]         │  │
  │  └────────────────────────────┘  │
  └──────────────┬───────────────────┘
                 │
                 │  인증 완료
                 ▼
  ┌──────────────────────────────────┐
  │      반려동물 등록 (Step 1/3)      │
  │                                  │
  │   "우리 아이를 알려주세요!"         │
  │                                  │
  │   [사진 추가] (선택)               │
  │   이름: [___________] (필수)      │
  │   종류: [강아지] [고양이] (필수)    │
  │   품종: [검색/선택____] (선택)     │
  │                                  │
  │          [다음 →]                 │
  └──────────────┬───────────────────┘
                 │
                 ▼
  ┌──────────────────────────────────┐
  │   기본 정보 입력 (Step 2/3)       │
  │                                  │
  │   생년월일: [____년 __월 __일]     │
  │    또는 나이: [__]살 (선택)        │
  │   성별:  [남아] [여아] (선택)      │
  │   중성화: [O] [X] (선택)          │
  │   체중:  [___] kg (선택)          │
  │                                  │
  │   [건너뛰기]     [다음 →]         │
  └──────────────┬───────────────────┘
                 │
                 ▼
  ┌──────────────────────────────────────────────┐
  │       케어 항목 선택 (Step 3/3)                │
  │                                              │
  │   "초코에게 필요한 관리를 선택해주세요!"         │
  │                                              │
  │   ── 위생 ──────────────────────              │
  │   [v] 목욕 (2주마다)                          │
  │   [v] 발톱 깎기 (2주마다)                      │
  │   [ ] 귀 청소 (1주마다)                        │
  │   [v] 양치 (매일)                              │
  │   [ ] 빗질 (3일마다)                           │
  │                                              │
  │   ── 건강 ──────────────────────              │
  │   [v] 예방접종 (1년마다)                        │
  │   [ ] 혈액검사 (6개월마다)                      │
  │   [v] 구충제 (1개월마다)                        │
  │   [v] 심장사상충 (1개월마다)                     │
  │   [ ] 체중 측정 (2주마다)                       │
  │                                              │
  │   ── 생활 ──────────────────────              │
  │   [ ] 물 갈기 (매일)                           │
  │   [v] 사료 주문 (1개월마다)                     │
  │   [ ] 장난감 세척 (1주마다)                     │
  │                                              │
  │   * 종(강아지/고양이)에 따라 추천 항목 미리 선택됨  │
  │   * 주기는 기본값 제공, 나중에 수정 가능           │
  │                                              │
  │          [시작하기!]                            │
  └──────────────────┬─────────────────────────────┘
                     │
                     │  케어 항목 + 기본 주기 일괄 생성
                     │  첫 예정일 = 오늘 기준으로 자동 계산
                     │
                     ▼
  ┌──────────────────────────────────────────────┐
  │           알림 권한 요청                        │
  │                                              │
  │   "케어 시간을 놓치지 않도록                     │
  │    알림을 보내드릴까요?"                         │
  │                                              │
  │   [알림 받기]          [나중에]                 │
  └──────────────────┬─────────────────────────────┘
                     │
                     ▼
  ┌──────────────────────────────────────────────┐
  │           🎉 온보딩 완료!                      │
  │                                              │
  │   "초코의 케어 관리가 시작되었어요!"              │
  │   "등록된 항목: 7개"                           │
  │   "첫 알림이 내일 오전 9시에 도착할 거예요"       │
  │                                              │
  │          [홈으로 가기]                          │
  └──────────────────┬─────────────────────────────┘
                     │
                     ▼
              [홈 대시보드 도착]
```

### 단계별 상세

| 단계 | 화면 | 핵심 행동 | 입력 필드 | 비고 |
|------|------|-----------|-----------|------|
| 1 | 스플래시 | 자동 전환 (1.5초) | 없음 | 앱 로딩 중 표시 |
| 2 | 웰컴/온보딩 | 스와이프 3장 → "시작하기" | 없음 | 스킵 가능 |
| 3 | 회원가입 | 소셜 로그인 버튼 탭 | 이메일/비밀번호(이메일 가입 시) | 카카오 최우선 |
| 4 | 반려동물 등록 | 이름/종 입력 | 이름(필수), 종(필수), 품종(선택) | 사진은 스킵 가능 |
| 5 | 기본 정보 | 추가 정보 입력 | 생년월일, 성별, 중성화, 체중 (모두 선택) | "건너뛰기" 제공 |
| 6 | 케어 항목 선택 | 체크박스 토글 | 카테고리별 항목 체크 | 종에 따라 추천 프리셋 |
| 7 | 알림 권한 | 허용/거부 | 없음 | OS 권한 다이얼로그 |
| 8 | 완료 | 홈으로 이동 | 없음 | 축하 메시지 |

### 예외 흐름

```
[이미 계정이 있는 경우]
  회원가입 화면 → "이미 계정이 있어요" 탭 → 로그인 → 홈 대시보드

[소셜 로그인 실패]
  에러 메시지 표시 → 다른 방법으로 시도 유도

[반려동물 등록 중 이탈]
  다음 앱 진입 시 이어서 진행 (등록 완료 전까지 온보딩 상태 유지)

[케어 항목 0개 선택]
  "최소 1개 이상 선택해주세요" 안내 메시지
```

## 2. 일상 사용 플로우 (핵심)

### 시나리오
> 보호자가 아침에 Push 알림을 받고 앱에 진입하여,
> 오늘 해야 할 케어를 확인하고 완료 버튼을 탭하는 핵심 루프

### 플로우 다이어그램

```
┌─────────────────────────────────────────────────────────────────┐
│                    일상 사용 플로우 (핵심 루프)                     │
└─────────────────────────────────────────────────────────────────┘

                    ┌──────────────┐
                    │  오전 9시     │
                    │  (설정된 시간) │
                    └──────┬───────┘
                           │
                           ▼
  ┌──────────────────────────────────────────────┐
  │            Push 알림 수신                      │
  │                                              │
  │  "초코 발톱 깎기 할 시간이에요! 🐾"             │
  │  "오늘 해야 할 케어가 3건 있어요"               │
  │                                              │
  └──────────────────┬─────────────────────────────┘
                     │
                     │  알림 탭
                     ▼
  ┌──────────────────────────────────────────────────────────┐
  │                    홈 대시보드                              │
  │                                                          │
  │  ┌─ 오늘 할 일 ─────────────────────────────────────┐     │
  │  │                                                  │     │
  │  │  🔴 발톱 깎기 (1일 지남)          [완료 ✓]         │     │
  │  │  🟡 양치 (오늘)                  [완료 ✓]         │     │
  │  │  🟡 귀 청소 (오늘)               [완료 ✓]         │     │
  │  │                                                  │     │
  │  └──────────────────────────────────────────────────┘     │
  │                                                          │
  │  ┌─ 곧 다가오는 일정 ───────────────────────────────┐     │
  │  │  🟢 목욕 (3일 후)                                │     │
  │  │  🟢 구충제 (5일 후)                               │     │
  │  └──────────────────────────────────────────────────┘     │
  │                                                          │
  └──────────────────────────────────────────────────────────┘
                     │
                     │  "완료 ✓" 버튼 탭 (1탭)
                     ▼
  ┌──────────────────────────────────────────────────────────┐
  │              완료 처리 (즉시 반응)                          │
  │                                                          │
  │   ✅ "발톱 깎기 완료!"                                    │
  │                                                          │
  │   완료일: 2026-03-13 (오늘)                               │
  │   다음 예정일: 2026-03-27 (14일 후)                       │
  │                                                          │
  │   [다른 날짜로 기록]  [메모 추가]  [취소]                   │
  │                                                          │
  │   * 토스트 메시지로 간결하게 표시                            │
  │   * 2초 후 자동 닫힘                                      │
  │   * "취소"로 실수 되돌리기 가능                              │
  └──────────────────────────────────────────────────────────┘
                     │
                     │  자동으로 다음 예정일 생성
                     │  홈 대시보드 목록에서 해당 항목 사라짐
                     ▼
  ┌──────────────────────────────────────────────────────────┐
  │              홈 대시보드 (업데이트됨)                        │
  │                                                          │
  │  ┌─ 오늘 할 일 ──────────────────────────────────┐       │
  │  │  ✅ 발톱 깎기 (완료)        ← 취소선/회색 처리   │       │
  │  │  🟡 양치 (오늘)              [완료 ✓]           │       │
  │  │  🟡 귀 청소 (오늘)           [완료 ✓]           │       │
  │  └───────────────────────────────────────────────┘       │
  │                                                          │
  │  ┌─ 곧 다가오는 일정 ──────────────────────────────┐      │
  │  │  🟢 목욕 (3일 후)                               │      │
  │  │  🟢 구충제 (5일 후)                              │      │
  │  │  🟢 발톱 깎기 (14일 후)    ← 새로 추가됨          │      │
  │  └───────────────────────────────────────────────┘       │
  └──────────────────────────────────────────────────────────┘
```

### 핵심 루프 요약

```
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌──────────────┐
│  알림    │────▶│  확인    │────▶│  완료   │────▶│  다음 일정    │
│  수신    │     │  (1탭)  │     │  (1탭)  │     │  자동 생성    │
└─────────┘     └─────────┘     └─────────┘     └──────┬───────┘
     ▲                                                  │
     │              반자동 케어 루프                       │
     └──────────────────────────────────────────────────┘
```

### 단계별 상세

| 단계 | 행동 | 탭 수 | 소요 시간 | 시스템 반응 |
|------|------|-------|-----------|-------------|
| 1 | 알림 수신 | 0 | - | Push 알림 자동 발송 |
| 2 | 알림 탭 → 앱 진입 | 1 | 1초 | 홈 대시보드 표시 |
| 3 | 완료 버튼 탭 | 1 | < 0.3초 | 완료 토스트 + 다음 일정 생성 |
| 4 | 확인 (자동) | 0 | 2초 | 토스트 자동 닫힘, 목록 업데이트 |

**총 소요: 2탭, 약 3초 -- "최소 입력" 원칙 충족**

### 예외 흐름

```
[앱을 열지 않고 무시한 경우]
  다음 날 리마인드 알림 재발송
  홈 대시보드에 빨간색(지남) 표시

[완료 대신 "다른 날짜로 기록" 선택]
  날짜 피커 표시 → 과거 날짜 선택 → 해당 날짜 기준으로 다음 일정 재계산

[실수로 완료 버튼 탭]
  토스트 내 "취소" 버튼 (2초 이내) → 완료 취소 → 원래 상태 복원

[오프라인 상태]
  완료 체크 로컬 저장 → 온라인 복구 시 자동 동기화 (5초 이내)

[다중 반려동물인 경우]
  홈 상단 반려동물 프로필 탭 전환 → 선택한 아이의 할 일만 표시
  "전체" 탭: 모든 아이의 할 일 통합 표시
```

## 3. 케어 항목 추가 플로우

### 시나리오
> 보호자가 새로운 케어 항목(예: "빗질")을 추가하고
> 반복 주기와 알림을 설정하는 과정

### 플로우 다이어그램

```
┌─────────────────────────────────────────────────────────────────┐
│                    케어 항목 추가 플로우                           │
└─────────────────────────────────────────────────────────────────┘

  [홈 대시보드]
       │
       │  하단 네비 "케어" 탭 선택
       ▼
  ┌──────────────────────────────────────────────────────────┐
  │                    케어 관리 화면                          │
  │                                                          │
  │  반려동물: [초코 ▼]  ← 다마리 시 전환                      │
  │                                                          │
  │  ── 위생 ──────────────────────────────────              │
  │  🛁 목욕        D-3 (3일 후)          [완료 ✓]            │
  │  💅 발톱 깎기    D+1 (1일 지남) 🔴     [완료 ✓]            │
  │                                                          │
  │  ── 건강 ──────────────────────────────────              │
  │  💉 예방접종     D-45 (45일 후)        [완료 ✓]            │
  │                                                          │
  │              [+ 항목 추가]                                 │
  └──────────────────┬─────────────────────────────────────────┘
                     │
                     │  [+ 항목 추가] 버튼 탭
                     ▼
  ┌──────────────────────────────────────────────────────────┐
  │              항목 추가 (Step 1: 카테고리 선택)               │
  │                                                          │
  │   "어떤 종류의 케어인가요?"                                 │
  │                                                          │
  │   ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐       │
  │   │ 🧴     │  │ 🏥     │  │ 🏠     │  │ ✏️     │       │
  │   │ 위생   │  │ 건강   │  │ 생활    │  │ 직접   │       │
  │   │        │  │        │  │        │  │ 입력   │       │
  │   └────────┘  └────────┘  └────────┘  └────────┘       │
  │                                                          │
  └──────────────────┬─────────────────────────────────────────┘
                     │
                     │  카테고리 탭 (예: "위생")
                     ▼
  ┌──────────────────────────────────────────────────────────┐

```

```
[1회성 항목 등록 (주기 없음)]
  주기 설정 단계에서 "1회성" 토글 → 특정 날짜만 지정 → 저장

[등록 중 뒤로가기]
  "변경사항을 저장하지 않고 나가시겠어요?" 확인 다이얼로그

[이미 등록된 항목 선택 시도]
  비활성 상태 + "이미 등록된 항목이에요" 안내
```

```

```

### 단계별 상세

| 4 | 지출 추가 | 카테고리 선택 | 필수 |
| 5 | 지출 추가 | 금액 입력 | 필수 |
| 6 | 지출 추가 | 내역 입력 | 선택 (빠른 입력 칩 제공) |
| 7 | 지출 추가 | 날짜 선택 | 선택 (기본값: 오늘) |
| 8 | 지출 추가 | 메모 입력 | 선택 |
| 9 | 지출 추가 | [저장하기] | 필수 |

### 예외 흐름

```

[금액 미입력]
  [저장하기] 비활성 상태, 금액 필드 포커스 + 안내

[최근 입력 재사용]
  "빠른 입력" 칩 탭 → 카테고리+내역+금액 자동 채움 → 확인 후 저장

[지출 수정]
  최근 내역 리스트에서 항목 탭 → 수정 화면 (동일 폼) → 저장

[지출 삭제]
  항목 왼쪽 스와이프 → 삭제 버튼 노출 → 탭 → "삭제하시겠어요?" 확인
```

## 5. 미루기 플로우

### 시나리오
> 보호자가 오늘 해야 할 케어를 수행하지 못했을 때,
> 일정을 미루고 다음 일정을 조정하는 과정
> (v1.1 기능이지만, UX 설계는 미리 준비)

### 플로우 다이어그램

```
┌─────────────────────────────────────────────────────────────────┐
│                    미루기 플로우                                   │
└─────────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────┐
  │            Push 알림 또는 홈 대시보드                       │
  │                                                          │
  │  🔴 발톱 깎기 (1일 지남)          [완료 ✓]                 │
  │                                                          │
  └──────────────────────────────────────────────────────────┘
       │
       │  항목 영역 길게 누르기(롱프레스)
       │  또는 왼쪽 스와이프
       ▼
  ┌──────────────────────────────────────────────────────────┐
  │              액션 메뉴                                     │
  │                                                          │
  │   [✓ 완료하기]                                            │
  │   [⏰ 미루기]                                              │
  │   [📝 상세 보기]                                           │
  │                                                          │
  └──────────────────┬─────────────────────────────────────────┘
                     │
                     │  "미루기" 선택
                     ▼
  ┌──────────────────────────────────────────────────────────┐
  │              미루기 옵션 (바텀시트)                          │
  │                                                          │
  │   "발톱 깎기를 언제로 미룰까요?"                             │
  │                                                          │
  │   ┌──────────────────────────────────────────────┐       │
  │   │  [내일]           2026-03-14 (토)             │       │
  │   │  [3일 뒤]         2026-03-16 (월)             │       │
  │   │  [이번 주말]       2026-03-15 (일)             │       │
  │   │  [1주 뒤]         2026-03-20 (금)             │       │
  │   │  [직접 선택 📅]                                │       │
  │   └──────────────────────────────────────────────┘       │
  │                                                          │
  │   ── 다음 일정 미리보기 ───────────────────                │
  │   "미루기 후 다음 예정일: 3월 30일 (14일 후)"               │
  │   * 미룬 날짜 기준으로 주기 재계산됨                         │
  │                                                          │
  │   ── 옵션 ──────────────────────────────                 │
  │   [ ] 다음 일정은 원래 주기 유지                            │
  │       (미룬 날짜가 아닌 원래 예정일 기준으로 계산)            │
  │                                                          │
  └──────────────────┬─────────────────────────────────────────┘
                     │
                     │  미루기 옵션 선택 (예: "3일 뒤")
                     ▼
  ┌──────────────────────────────────────────────────────────┐
  │              미루기 완료 피드백                              │
  │                                                          │
  │   "발톱 깎기를 3월 16일로 미뤘어요"                         │
  │   "그때 다시 알려드릴게요!"                                 │
  │                                                          │
  │   * 토스트 2초 → 홈 대시보드 복귀                           │
  │   * 홈에서 해당 항목 사라짐 (미래 일정으로 이동)              │
  └──────────────────────────────────────────────────────────┘
```

### 미루기 시 일정 재계산 로직

```
  [기본 동작: 미룬 날짜 기준 재계산]

  예시) 발톱 깎기: 14일 주기

  원래 예정일: 3/13
  미루기: 3/16 (3일 뒤)
  → 다음 예정일: 3/30 (3/16 + 14일)

  [옵션: 원래 주기 유지]

  원래 예정일: 3/13
  미루기: 3/16 (3일 뒤)
  → 다음 예정일: 3/27 (3/13 + 14일, 원래 기준)
```

### 단계별 상세

| 단계 | 화면 | 핵심 행동 | 탭 수 |
|------|------|-----------|-------|
| 1 | 홈 대시보드 | 항목 롱프레스/스와이프 | 1 |
| 2 | 액션 메뉴 | "미루기" 선택 | 1탭 |
| 3 | 미루기 옵션 | 빠른 선택 탭 | 1탭 |
| **합계** | | | **3탭** -- 원칙 충족 |

### 예외 흐름

```
[Push 알림에서 직접 미루기]
  알림 액션 버튼 "오늘 못 했어요" → 앱 열림 → 미루기 옵션 바텀시트

[미루기 취소]
  토스트 내 "취소" 버튼 (2초 이내) → 원래 예정일로 복원

[반복적으로 미루는 경우]
  3회 이상 미루기 시 "이 항목의 주기를 조정해볼까요?" 제안
  (주기가 현실과 맞지 않는 것일 수 있으므로)

[과거 날짜로 미루기 시도]
  불가 — 과거 날짜는 선택 불가능 (날짜 피커에서 비활성)
```

### 다마리 가정 추가 플로우

```
  ┌──────────────────────────────────────────────────────────┐
  │                    가계부 화면 (다마리)                     │
  │                                                          │
  │  반려동물: [전체 ▼]  [초코]  [두부]                        │
  │                                                          │
  │  * "전체": 모든 아이 통합 통계                              │
  │  * 아이 선택 시: 해당 아이만의 지출 통계                     │
  │                                                          │
  │  ── 아이별 지출 비교 (전체 선택 시) ────────              │
  │                                                          │
  │  초코   ████████████████   185,000원  (76%)              │
  │  두부   █████              60,000원   (24%)              │
  │                                                          │
  └──────────────────────────────────────────────────────────┘
```

### 단계별 상세

| 단계 | 화면 | 핵심 행동 | 탭 수 |
|------|------|-----------|-------|
| 1 | 홈 → 가계부 | 하단 네비 "가계부" 탭 | 1탭 |
| 2 | 가계부 | 월별 총지출 / 차트 확인 | 0탭 (바로 보임) |
| 3 | 가계부 | 월 이동 (◀ ▶) | 1탭 |
| 4 | 가계부 | 카테고리 바 탭 → 상세 | 1탭 |
| **합계** | | | **2~3탭** -- 원칙 충족 |

### 상세 인터랙션

```
[월 이동]
  ◀ ▶ 버튼 탭 또는 좌우 스와이프
  → 해당 월 데이터 로드 (총지출 + 차트 + 내역 모두 갱신)

[카테고리 바 차트 탭]
  → 해당 카테고리 상세 바텀시트 올라옴
  → 해당 카테고리의 모든 지출 내역 + 전월 비교

[내역 항목 탭]
  → 지출 상세/수정 화면 이동

[반려동물 필터]
  상단 칩 탭 → 해당 아이만의 통계 표시
  "전체" 선택 시 아이별 비교 차트 추가 표시

[데이터 없는 달]
  "이번 달은 기록된 지출이 없어요"
  [+ 지출 추가하기] 버튼 표시
```

### 예외 흐름

```
[처음 사용 (데이터 0건)]
  빈 상태 일러스트 + "지출을 기록하면 여기에 통계가 표시돼요"
  [+ 첫 지출 기록하기] CTA 버튼

[특정 카테고리 지출 0건인 달]
  해당 카테고리 바 차트에서 제외 (0원인 카테고리는 표시하지 않음)

[매우 오래된 달 조회]
  무한 스크롤 아닌 ◀ ▶ 버튼 방식
  데이터 있는 첫 달까지만 이동 가능
```

## 하단 네비게이션 구조

```
┌─────────────────────────────────────────────────┐
│  🏠 홈    🐾 케어    💰 가계부    👤 프로필       │
└─────────────────────────────────────────────────┘

  홈:      오늘 할 일 + 곧 다가오는 일 + 지출 요약
  케어:    케어 항목 관리 + 완료 + 추가/수정
  가계부:  월별 통계 + 지출 내역 + 추가
  프로필:  반려동물 프로필 + 설정(알림, 로그아웃)
```
