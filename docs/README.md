# Documentation Map

이 디렉터리는 현재 운영에 필요한 문서와 과거 작업 메모를 분리해서 유지한다. 실행과 점검에 직접 쓰는 문서는 `docs/` 루트에 두고, 설계 초안이나 초기 메모는 `docs/archive/` 아래로 옮긴다.

제품과 화면 흐름을 이해하려면 `PRD.md`, `user-flows.md`, `wireframes.md`를 먼저 본다. 데이터와 인터페이스는 `erd.md`, `api-spec.md`, `tech-stack.md`에 정리되어 있다. 운영 중 장애 대응이 필요하면 `auth-login-checklist.md`와 `dev-log.md`를 기준으로 확인한다. 추천 카탈로그 운영 규칙과 시드 방법은 `recommendation-catalog.md`에 따로 정리한다.

테스트 원칙과 방향은 `test-strategy.md`에서 관리한다. 현재 작업 항목과 회고성 교훈은 문서 디렉터리가 아니라 `tasks/` 아래에서 관리한다. 문서가 새로 생기면 루트에 둘지 `archive/`에 둘지 먼저 판단하고, 운영에 직접 쓰이지 않는 초안은 루트로 올리지 않는다.
