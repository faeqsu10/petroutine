## 1. Product Overview

### One-line Description

반려동물 케어 주기를 자동으로 관리하고, 지출을 추적하여 "기억에 의존하지 않는 반려동물 관리 시스템"을 제공하는 모바일 앱.

### Problem Statement

반려동물 보호자는 발톱 깎기, 목욕, 양치, 귀 청소, 예방접종, 혈액검사 등 반복적인 케어 항목을 **기억에 의존하여 관리**하고 있다. 이로 인해 다음과 같은 문제가 발생한다:

1. **케어 시점 누락**: 해야 하는 건 아는데, 정확히 언제 했는지 기억나지 않아 미루다가 놓침
2. **지출 파악 불가**: 반려동물에 매달 얼마를 쓰는지 체감하지 못하며, 확인하려면 결제내역을 일일이 뒤져야 함
3. **정보 분산**: 카카오톡, 메모앱, 달력 등에 관리 정보가 흩어져 있어 체계적 관리가 불가능
4. **다견/다묘 가정의 혼란**: 여러 마리를 키우거나, 가족이 같이 돌보면 누가 언제 했는지 더 헷갈림

실제 사용자 대화에서 도출된 핵심 니즈:

> *"혈액검사한지 며칠 되었다 이런거? 병원 내역하고 연동하거나 내가 직접 입력해서"* — 강선호
>
> *"발톱깎은지 며칠 되었다... 샤워시킨지 며칠되었다... 내가 체크안해도 알아서 체크해주는 그런 기능?"* — 강선호
>
> *"최초 1회만 지정해주면 그담부턴 앱에서 알람올때 갈고, 버튼하나만 누르면 다음 시점으로 이동되서"* — 강선호
>
> *"매번 구매한 내역 찾아가면서 얼마썼는지 찾기 힘듦"* — 강선호

### Target Users (Personas)

#### Persona 1: 바쁜 1인 보호자 (Primary)

| 항목 | 내용 |
|------|------|
| **연령대** | 20~30대 |
| **특징** | 직장인, 혼자 반려동물 1~2마리 돌봄 |
| **성향** | 귀차니즘이 있지만 반려동물에 대한 애정은 강함 |
| **Pain Point** | 바쁜 일상 속 케어 시점을 자주 놓침, "언제 했더라?" 반복 |
| **니즈** | 알림 받고 버튼 한 번이면 끝나는 단순한 관리 시스템 |
| **사용 환경** | 모바일 중심 (iOS/Android) |

#### Persona 2: 다견/다묘 가정 보호자

| 항목 | 내용 |
|------|------|
| **연령대** | 20~40대 |
| **특징** | 반려동물 2마리 이상, 각각 케어 주기가 다름 |
| **Pain Point** | 아이별로 언제 뭘 했는지 기억이 뒤섞임, 지출도 분리 파악 어려움 |
| **니즈** | 아이별 케어 이력/지출 분리 관리, 한눈에 전체 현황 파악 |

#### Persona 3: 공동 돌봄 보호자

| 항목 | 내용 |
|------|------|
| **연령대** | 20~30대 |
| **특징** | 가족 또는 연인과 함께 반려동물 돌봄 |
| **Pain Point** | 누가 했는지 모름, 중복 수행 또는 누락 발생 |
| **니즈** | 공유 관리, 완료 이력에 수행자 표시 |

### Core Value Proposition

> **"기억에 의존하지 않는 반려동물 관리 시스템"**

- 사용자가 원하는 것은 **기록**이 아니라 **안 놓치는 것**
- 매번 생각하지 않아도 알림이 오고, 버튼 하나로 다음 일정이 자동 생성됨
- 최소한의 입력으로 굴러가는 **반자동 케어 루프**
- "지금 뭘 해야 하지?"에 즉시 답할 수 있는 **운영 중심 대시보드**

## 2. User Stories (MVP Scope)

### US-01: 반려동물 프로필 등록

> **As a** 보호자, **I want** 내 반려동물의 기본 정보(이름, 종, 품종, 나이, 체중, 사진)를 등록할 수 있기를, **so that** 앱이 내 아이에 맞는 케어 관리를 제공할 수 있다.

**Acceptance Criteria:**
- [ ] 이름(필수), 종(강아지/고양이, 필수), 품종(선택), 생년월일 또는 나이(선택), 체중(선택), 사진(선택)을 입력할 수 있다
- [ ] 종 선택 시 강아지/고양이 중 선택할 수 있다
- [ ] 품종은 검색 가능한 목록에서 선택하거나 직접 입력할 수 있다
- [ ] 프로필 등록 후 수정이 가능하다
- [ ] 여러 마리의 반려동물을 등록할 수 있다
- [ ] 등록된 반려동물 목록을 조회할 수 있다
- [ ] 반려동물을 삭제할 수 있다 (확인 dialog 포함)

### US-02: 케어 항목 관리

> **As a** 보호자, **I want** 관리할 케어 항목(발톱, 목욕, 양치, 귀청소, 혈액검사, 예방접종 등)을 추가/수정/삭제할 수 있기를, **so that** 내 아이에게 필요한 관리 항목을 맞춤 설정할 수 있다.

**Acceptance Criteria:**
- [ ] 기본 템플릿 항목이 카테고리별로 제공된다:
  - 위생: 목욕, 발톱, 귀청소, 양치, 빗질
  - 건강: 혈액검사, 예방접종, 구충, 심장사상충, 약 복용, 체중 측정
  - 생활: 물 갈기, 사료 주문, 모래 갈기, 장난감 세척, 하우스 청소
- [ ] 템플릿에서 원하는 항목을 선택하여 추가할 수 있다
- [ ] 사용자가 커스텀 항목을 직접 추가할 수 있다 (항목명, 카테고리 지정)
- [ ] 등록된 항목을 수정할 수 있다 (항목명, 카테고리, 주기)
- [ ] 등록된 항목을 삭제할 수 있다 (확인 dialog 포함)
- [ ] 각 케어 항목은 특정 반려동물에 연결된다

### US-03: 케어 주기 설정

> **As a** 보호자, **I want** 각 케어 항목에 반복 주기(N일/N주/N개월마다)를 설정할 수 있기를, **so that** 다음에 해야 할 시점을 시스템이 자동으로 계산해준다.

**Acceptance Criteria:**
- [ ] 주기 단위를 선택할 수 있다: 일(days), 주(weeks), 개월(months)
- [ ] 주기 값(N)을 숫자로 입력할 수 있다 (최소 1)
- [ ] 주기 설정 시 최초 수행일(또는 마지막 수행일)을 입력할 수 있다
- [ ] 주기를 설정하면 다음 예정일이 자동으로 계산되어 표시된다
- [ ] 주기를 수정하면 다음 예정일이 재계산된다
- [ ] 주기 없이 1회성 항목도 등록할 수 있다 (특정 날짜 지정)

### US-04: 완료 체크 및 자동 다음 일정 생성

> **As a** 보호자, **I want** 케어 항목을 완료했을 때 버튼 하나만 누르면 다음 예정일이 자동으로 생성되기를, **so that** 최소한의 노력으로 케어 관리가 지속된다.

**Acceptance Criteria:**
- [ ] 각 케어 항목에 "완료" 버튼이 있다
- [ ] 완료 버튼을 누르면 완료일이 오늘 날짜로 기록된다
- [ ] 완료 시 설정된 주기에 따라 다음 예정일이 자동 계산된다
- [ ] 완료 이력(수행일, 수행자)이 기록된다
- [ ] 완료 취소(실수로 눌렀을 때 되돌리기)가 가능하다
- [ ] 완료일을 오늘이 아닌 다른 날짜로 지정할 수도 있다 (과거 날짜 소급 입력)

### US-05: 홈 대시보드

> **As a** 보호자, **I want** 홈 화면에서 오늘 해야 할 일, 곧 다가오는 일정, 이번 달 지출을 한눈에 볼 수 있기를, **so that** "지금 뭘 하면 되지?"를 즉시 파악할 수 있다.

**Acceptance Criteria:**
- [ ] 오늘 해야 할 케어 항목 목록이 표시된다 (예정일이 오늘이거나 지난 항목)
- [ ] 곧 다가오는 일정(향후 7일 이내)이 표시된다
- [ ] 이번 달 총 지출 금액이 표시된다
- [ ] 오래 미뤄진 항목(예정일이 지난 항목)이 강조 표시된다
- [ ] 반려동물이 여러 마리인 경우 전체 보기 / 아이별 보기를 전환할 수 있다
- [ ] 홈 화면에서 바로 완료 체크를 할 수 있다
- [ ] 최근 완료한 항목이 표시된다

### US-06: Push 알림

> **As a** 보호자, **I want** 케어 예정일에 Push 알림을 받을 수 있기를, **so that** 앱을 열지 않아도 해야 할 일을 놓치지 않는다.

**Acceptance Criteria:**
- [ ] 케어 항목 예정일 당일에 Push 알림이 발송된다
- [ ] 알림 시간을 사용자가 설정할 수 있다 (기본값: 오전 9시)
- [ ] 알림을 탭하면 해당 케어 항목 상세 화면으로 이동한다
- [ ] 항목별로 알림 ON/OFF를 설정할 수 있다
- [ ] 완료하지 않은 항목은 다음 날에도 리마인드 알림이 발송된다
- [ ] 전체 알림 ON/OFF를 설정할 수 있다

### US-07: 지출 기록

> **As a** 보호자, **I want** 반려동물 관련 지출을 카테고리/금액/메모와 함께 기록할 수 있기를, **so that** 내 아이에게 얼마를 쓰고 있는지 파악할 수 있다.

**Acceptance Criteria:**
- [ ] 지출 항목을 등록할 수 있다: 날짜(필수), 카테고리(필수), 금액(필수), 메모(선택)
- [ ] 지출 카테고리가 제공된다: 사료, 간식, 병원비, 미용, 용품, 보험, 기타
- [ ] 커스텀 카테고리를 추가할 수 있다
- [ ] 지출을 특정 반려동물에 연결할 수 있다 (공통 지출도 가능)
- [ ] 등록된 지출을 수정/삭제할 수 있다
- [ ] 최근 지출 내역을 목록으로 조회할 수 있다
- [ ] 빠른 입력을 위해 최근 입력 항목을 재사용할 수 있다

### US-08: 월별 지출 통계

> **As a** 보호자, **I want** 월별 총 지출, 카테고리별 지출, 아이별 지출 통계를 볼 수 있기를, **so that** 소비 패턴을 파악하고 관리할 수 있다.

**Acceptance Criteria:**
- [ ] 월별 총 지출 금액이 표시된다
- [ ] 카테고리별 지출 비율과 금액이 차트로 표시된다
- [ ] 반려동물별 지출 비율과 금액이 표시된다 (다견/다묘 가정)
- [ ] 이전 달과의 지출 비교가 가능하다
- [ ] 월 단위로 이동하며 조회할 수 있다
- [ ] 카테고리를 탭하면 해당 카테고리의 상세 지출 내역을 볼 수 있다

| **지출 관리** | 지출 기록 (날짜, 카테고리, 금액, 메모), 기본 + 커스텀 카테고리, 반려동물 연결, 수정/삭제, 최근 항목 재사용 |
| **지출 통계** | 월별 총지출, 카테고리별 차트, 아이별 지출, 월 이동 조회, 카테고리별 상세 내역 |
| **플랫폼** | iOS, Android (Cross-platform) |

| 영역 | 제외 항목 | 사유 |
|------|-----------|------|

| **제품 추천** | 사료/간식/용품 추천, 적합도 분석 | 데이터 축적 후 v2.0 |
| **커머스 연동** | 제휴 링크, 쿠팡파트너스 등 | 추천 기능과 함께 v2.0 |
| **병원 연결** | 위치 기반 병원 검색, 예약 연동 | 파트너십 필요, v3.0 |
| **건강 기록 심화** | 병원 방문 기록, 예방접종 이력 관리, 체중 변화 그래프, 진료 리포트 | v2.0 |
| **AI 기능** | 이상행동 감지, 건강 요약, 스마트 주기 추천 | 데이터 부족, 장기 과제 |
| **미디어 관리** | 사진/영상 자동 정리, 성장 타임라인 | 핵심 가치와 거리 있음 |
| **웹 버전** | 브라우저 접근 | 모바일 우선 |
| **미루기 기능** | 날짜 변경 미루기 | v1.1에서 구현 |
| **소셜/공유** | 커뮤니티, SNS 공유 | 초기 집중 방해 |

### MVP 핵심 설계 원칙

1. **입력 최소화**: 사용자가 "열심히 기록하는 앱"이 아니라 "최소 입력으로 굴러가는 앱"
2. **운영 중심**: "무엇을 입력할까?"가 아니라 "지금 뭘 하면 되지?"를 보여주는 화면
3. **반자동 케어 루프**: 최초 1회 설정 → 알림 → 완료 버튼 → 자동 다음 일정 → 반복
4. **기록 피로 제거**: 완료 체크는 1탭, 지출 입력은 최소 필드

| 지표 | 정의 | 목표 (출시 후 3개월) |

| 지표 | 정의 | 목표 (출시 후 3개월) |
|------|------|----------------------|
| **등록 반려동물 수** | 총 등록된 반려동물 프로필 수 | 2,000마리 |

### North Star Metric (최상위 지표)

> **주간 완료 체크 횟수 (Weekly Completion Checks)**
>
> 이 지표가 서비스의 핵심 가치 전달을 가장 직접적으로 반영한다.
> 사용자가 알림을 받고, 케어를 수행하고, 완료 버튼을 누르는 행위가
> "기억에 의존하지 않는 관리 시스템"이 작동하고 있다는 증거이기 때문이다.

### v1.0 — MVP (목표: 개발 시작 후 6~8주)

**테마: "반자동 케어 루프 + 반려동물 가계부"**

| M3: 대시보드 + 알림 | 홈 화면 (오늘 할 일, 다가오는 일정), Push 알림 연동 | 5~6주차 |
