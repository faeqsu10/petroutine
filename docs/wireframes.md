## 설계 원칙

| 원칙 | 적용 |
|------|------|
| **완료 버튼 최우선** | 모든 케어 카드에 눈에 띄는 완료 CTA 배치 |
| **긴급도 색상** | 빨강(overdue, 지남) / 노랑(due, 오늘) / 초록(upcoming, 여유) |
| **3탭 이내 완료** | 핵심 동작(완료 체크)은 알림 탭 -> 완료 버튼 = 2탭 |
| **운영앱 느낌** | "지금 뭘 하면 되지?"에 즉시 답하는 대시보드 |
| **모바일 퍼스트** | 한 손 조작, 하단 네비, 큰 터치 영역 (44px 이상) |
| **기록 피로 최소화** | 최초 설정 이후 거의 자동, 완료 체크 1탭 |

## 1. 로그인

소셜 로그인 중심. 카카오를 최상단 강조 CTA로 배치한다.

```
+---------------------------------------+
|             STATUS BAR                |
+---------------------------------------+
|                                       |
|                                       |
|                                       |
|           +-----------+               |
|           |    :paw:  |               |
|           | Petroutine|               |
|           +-----------+               |
|                                       |
|       "기억에 의존하지 않는             |
|        반려동물 관리"                   |
|                                       |
|                                       |
|                                       |
|   +-------------------------------+   |
|   |                               |   |
|   |    카카오로 시작하기      >>   |   |
|   |    [#FEE500 배경, 굵은 텍스트]  |   |
|   |                               |   |
|   +-------------------------------+   |
|                                       |
|   +-------------------------------+   |
|   |                               |   |
|   |  G  Google로 시작하기         |   |
|   |     [흰 배경, 회색 테두리]      |   |
|   |                               |   |
|   +-------------------------------+   |
|                                       |
|   +-------------------------------+   |
|   |                               |   |
|   |     Apple로 시작하기          |   |
|   |     [검정 배경, 흰 텍스트]      |   |
|   |                               |   |
|   +-------------------------------+   |
|                                       |
|   - - - - - - 또는 - - - - - -       |
|                                       |
|        이메일로 시작하기               |
|        [회색 텍스트 링크 스타일]        |
|                                       |
|                                       |
|     이미 계정이 있어요? [로그인]       |
|                                       |
+---------------------------------------+
```

**인터랙션:**
- 카카오 버튼: `#FEE500` 배경, 가장 큰 크기(높이 52px), 화살표 아이콘 -- 한국 시장 최우선 CTA
- Google 버튼: 흰색 배경 + `#E5E7EB` 테두리, Google 로고
- Apple 버튼: `#000000` 배경, Apple 로고 -- iOS PWA 사용자 대응
- 이메일: 텍스트 링크 스타일로 축소 배치 (fallback 용도)
- 소셜 로그인 실패 시 토스트 에러 메시지 표시
- 로그인 성공 -> 반려동물 있으면 홈 대시보드, 없으면 온보딩 시작

## 2. 온보딩 -- 반려동물 등록

온보딩 Step 1~2. 최소 필수 정보(이름, 종)만 요구하고 나머지는 선택.

```
+---------------------------------------+
|  < 뒤로                    건너뛰기   |
+---------------------------------------+
|                                       |
|  Step 1/3  ========>-----------       |
|                                       |
|    "우리 아이를 알려주세요!"            |
|                                       |
|          +------------+               |
|          |            |               |
|          |   [ 📷 ]   |  사진 추가    |
|          |            |  (선택)       |
|          +------------+               |
|                                       |
|  이름 *                               |
|  +-------------------------------+    |
|  |  예: 초코                      |    |
|  +-------------------------------+    |
|                                       |
|  종류 *                               |
|  +--------------+ +--------------+    |
|  |              | |              |    |
|  | [v] 강아지   | |  [ ] 고양이  |    |
|  |              | |              |    |
|  +--------------+ +--------------+    |
|                                       |
|  품종 (선택)                           |
|  +-------------------------------+    |
|  |  검색하거나 선택하세요...    🔍 |    |
|  +-------------------------------+    |
|                                       |
|  -- 추가 정보 (선택) ------[펼치기]-  |
|  |                                |   |
|  |  생년월일                       |   |
|  |  +---------------------------+ |   |
|  |  |  ____년  __월  __일        | |   |
|  |  +---------------------------+ |   |
|  |  또는 나이: [__]살             |   |
|  |                                |   |
|  |  성별             중성화        |   |
|  |  +-------+----+  +------+---+ |   |
|  |  | 남아  |여아 |  |  O   | X | |   |
|  |  +-------+----+  +------+---+ |   |
|  |                                |   |
|  |  체중                          |   |
|  |  +------------------+         |   |
|  |  |  ___  kg          |         |   |
|  |  +------------------+         |   |
|  |                                |   |
|  +--------------------------------+   |
|                                       |
|   +-------------------------------+   |
|   |                               |   |
|   |          다음  ->              |   |
|   |                               |   |
|   +-------------------------------+   |
|                                       |
+---------------------------------------+
```

**인터랙션:**
- 이름, 종류만 필수 -- 다른 필드는 "건너뛰기" 가능
- 종류 선택: 칩 버튼 토글 (한 쪽만 활성)
- 품종: 검색 가능한 드롭다운 + 직접 입력 모드
- "추가 정보"는 접힌 상태가 기본 -- 탭하면 생년월일/성별/중성화/체중 노출
- 사진: 카메라 또는 갤러리에서 선택 (원형 크롭)
- 등록 중 이탈 시 다음 진입 때 이어서 진행

## 3. 온보딩 -- 케어 항목 선택

Step 3/3. 종(강아지/고양이)에 따라 추천 항목이 미리 체크됨.

```
+---------------------------------------+
|  < 뒤로                               |
+---------------------------------------+
|                                       |
|  Step 3/3  ========================>  |
|                                       |
|    "초코에게 필요한 관리를              |
|     선택해주세요!"                     |
|                                       |
|  * 추천 항목이 미리 선택되어 있어요     |
|  * 주기는 나중에 수정할 수 있어요       |
|                                       |
|  -- 위생 ----------------------------  |
|                                       |
|  [v] 🛁  목욕              2주마다    |
|  [v] ✂️  발톱 깎기          2주마다    |
|  [ ] 👂  귀 청소            1주마다    |
|  [v] 🪥  양치               매일      |
|  [ ] 🖌️  빗질              3일마다    |
|                                       |
|  -- 건강 ----------------------------  |
|                                       |
|  [v] 💉  예방접종           1년마다    |
|  [ ] 🩸  혈액검사           6개월마다  |
|  [v] 💊  구충제             1개월마다  |
|  [v] ❤️  심장사상충          1개월마다  |
|  [ ] ⚖️  체중 측정          2주마다    |
|                                       |
|  -- 생활 ----------------------------  |
|                                       |
|  [ ] 💧  물 갈기             매일     |
|  [v] 📦  사료 주문          1개월마다  |
|  [ ] 🧸  장난감 세척         1주마다   |
|                                       |
|                                       |
|  선택된 항목: 7개                      |
|                                       |
|   +-------------------------------+   |
|   |                               |   |
|   |         시작하기!              |   |
|   |                               |   |
|   +-------------------------------+   |
|                                       |
+---------------------------------------+
```

**인터랙션:**
- 체크박스 토글로 항목 선택/해제
- 최소 1개 선택 필수 (0개 시 "최소 1개 이상 선택해주세요" 안내 메시지)
- 추천 항목은 종(강아지/고양이)에 따라 자동 프리셋
- 각 항목 옆 주기는 기본값 표시 (이후 케어 관리 화면에서 수정 가능)
- "시작하기!" 탭 시:
  - 선택된 항목 + 기본 주기 일괄 생성
  - 첫 예정일 = 오늘 기준으로 자동 계산
  - 알림 권한 요청 OS 다이얼로그 표시
  - 완료 축하 화면 -> 홈 대시보드 이동

## 4. 홈 대시보드

앱의 허브 화면. "지금 뭘 하면 되지?"에 즉시 답한다.

```
+---------------------------------------+
|  Petroutine              [초코 v] [+] |
+---------------------------------------+
|                                       |
|  -- 오늘 할 일 (3) -------- 긴급도순 --  |
|                                       |
|  +-----------------------------------+|
|  |                                   ||
|  | 🔴  발톱 깎기             +1일 지남||
|  |      초코                         ||
|  |      마지막: 3월 1일              ||
|  |                                   ||
|  |                        +--------+ ||
|  |                        | 완료 v | ||
|  |                        +--------+ ||
|  |                                   ||
|  +-----------------------------------+|
|                                       |
|  +-----------------------------------+|
|  |                                   ||
|  | 🟡  양치                    오늘  ||
|  |      초코                         ||
|  |      마지막: 어제                  ||
|  |                                   ||
|  |                        +--------+ ||
|  |                        | 완료 v | ||
|  |                        +--------+ ||
|  |                                   ||
|  +-----------------------------------+|
|                                       |
|  +-----------------------------------+|
|  |                                   ||
|  | 🟡  귀 청소                 오늘  ||
|  |      초코                         ||
|  |      마지막: 3월 6일              ||
|  |                                   ||
|  |                        +--------+ ||
|  |                        | 완료 v | ||
|  |                        +--------+ ||
|  |                                   ||
|  +-----------------------------------+|
|                                       |
|  -- 곧 다가오는 일정 -----------------  |
|                                       |
|  +-----------------------------------+|
|  |  🟢  목욕              3일 후     ||
|  |       초코             3월 16일   ||
|  +-----------------------------------+|
|  +-----------------------------------+|
|  |  🟢  구충제            5일 후     ||
|  |       초코             3월 18일   ||
|  +-----------------------------------+|
|                                       |
|  -- 이번 달 지출 ---------------------  |
|  +-----------------------------------+|
|  |                                   ||
|  |       245,000원                   ||
|  |       전월 대비 +32,000원  ▲       ||
|  |                                   ||
|  +-----------------------------------+|
|                                       |
+---------------------------------------+
|  🏠 홈  | 🐾 케어 | 💰 가계부 | ⚙️ 설정 |
+---------------------------------------+
```

**인터랙션:**
- **상단 반려동물 셀렉터**: [초코 v] 탭 시 드롭다운 -- 다마리 가정 시 아이 전환, "전체" 옵션으로 모든 아이 통합 표시
- **[+] 버튼**: 반려동물 추가 화면 이동
- **[완료 v] 버튼**: 핵심 CTA
  - `indigo-600` (#4F46E5) 배경, 흰 텍스트
  - 높이 40px, 최소 터치 영역 44px
  - 탭 시 완료 토스트 표시 (2초 자동 닫힘)
  - 완료된 카드는 취소선 + 회색 처리
- **케어 카드 탭**: 케어 항목 상세/이력 화면 이동
- **케어 카드 롱프레스**: 액션 메뉴 표시 (완료 / 미루기 / 상세)
- **긴급도 색상**:
  - 🔴 빨강 (`#EF4444`): overdue -- 예정일 지남
  - 🟡 노랑 (`#F59E0B`): due -- 오늘
  - 🟢 초록 (`#10B981`): pending -- 여유 있음
- **"이번 달 지출" 영역 탭**: 가계부 화면 이동
- 오늘 할 일이 모두 완료되면: "오늘의 케어를 모두 마쳤어요!" 축하 메시지

## 6. 케어 항목 추가

카테고리 선택 -> 항목 선택 -> 주기 설정. 한 화면에서 처리.

```
+---------------------------------------+
|  < 뒤로          케어 항목 추가        |
+---------------------------------------+
|                                       |
|  "어떤 종류의 케어인가요?"             |
|                                       |
|  +--------+  +--------+  +--------+  |
|  | 🧴     |  | 🏥     |  | 🏠     |  |
|  | 위생   |  | 건강   |  | 생활   |  |
|  +--------+  +--------+  +--------+  |
|                          +--------+   |
|                          | ✏️     |   |
|                          | 직접   |   |
|                          | 입력   |   |
|                          +--------+   |
|                                       |
|  -- "위생" 항목 ---------- (선택됨) -  |
|                                       |
|  +-----------------------------------+|
|  |  🛁 목욕              (등록됨)    ||
|  +-----------------------------------+|
|  +-----------------------------------+|
|  |  ✂️ 발톱 깎기          (등록됨)    ||
|  +-----------------------------------+|
|  +-----------------------------------+|
|  |  👂 귀 청소         추천: 1주     ||
|  +-----------------------------------+|
|  +-----------------------------------+|
|  |  🖌️ 빗질           추천: 3일      ||
|  +-----------------------------------+|
|  +-----------------------------------+|
|  |  + 직접 입력하기                  ||
|  +-----------------------------------+|
|                                       |
|  ===== 주기 설정 (항목 선택 시 노출) ==  |
|                                       |
|  🖌️ 빗질                              |
|                                       |
|  반복 주기                             |
|  +--------+ +----------+             |
```

## 7. 완료 모달

케어 완료 시 나타나는 UI. 기본은 토스트(빠른 처리), 상세 입력 시 바텀시트 확장.

### 7-A. 토스트 모드 (기본)

일상적인 완료는 토스트로 빠르게 처리한다. 2초 후 자동 닫힘.

```
+---------------------------------------+
|                                       |
|           (기존 화면 유지)             |
|                                       |
|                                       |
|                                       |
|                                       |
|                                       |
|                                       |
|  +-----------------------------------+|
|  |                                   ||
|  |  v  발톱 깎기 완료!               ||
|  |                                   ||
|  |  다음 예정일: 3/27 (14일 후)      ||
|  |                                   ||
|  |  [메모 추가]              [취소]  ||
|  |                                   ||
|  +-----------------------------------+|
|                                       |
+---------------------------------------+
| 🏠 홈  | 🐾 케어 | 💰 가계부 | ⚙️ 설정 |
+---------------------------------------+

* 2초 후 자동 닫힘
* "취소" 탭 시 완료 되돌리기
* "메모 추가" 탭 시 바텀시트로 확장
```

### 7-B. 바텀시트 모드 (상세)

메모 입력이나 날짜 변경이 필요한 경우.

```
+---------------------------------------+
|                                       |
|         (기존 화면 어두워짐)            |
|                                       |
|                                       |
|                                       |
+=======================================+
|                                       |
|  v  발톱 깎기 완료!                   |
|                                       |
|  완료일: 2026-03-13 (오늘)            |
|  다음 예정일: 2026-03-27 (14일 후)    |
|                                       |
|  메모 (선택)                          |
|  +-----------------------------------+|
|  |  예: 뒷발만 깎음                  ||
|  +-----------------------------------+|
|                                       |
|  [다른 날짜로 기록]                    |
|                                       |
|   +-------------------------------+   |
|   |           확인                |   |
|   +-------------------------------+   |
|                                       |
|   [취소]                              |
|                                       |
+---------------------------------------+
```

**인터랙션:**
- **기본 동작**: 토스트 모드 (2초 자동 닫힘, 최소 방해)
- **[메모 추가]** 탭: 토스트에서 바텀시트로 확장
- **[다른 날짜로 기록]**: 날짜 피커 표시 (과거 날짜 선택 가능, 소급 입력)
- **[취소]**: 2초 이내 탭 시 완료 취소, 원래 상태 복원 (undone)
- **확인 후 시스템 동작**:
  - `care_logs` INSERT (완료 기록)
  - 현재 스케줄 status -> `'completed'`
  - 다음 예정일 자동 계산 (`completed_at + cycle_interval`)
  - 새 스케줄 INSERT (status: `'pending'`)
  - 홈 대시보드에서 해당 카드 취소선+회색 처리
  - 곧 다가오는 일정에 다음 예정일 추가

## 11. 하단 네비게이션

4개 탭, 하단 고정. Safe area 대응.

```
+---------------------------------------+
|                                       |
|            (화면 콘텐츠)               |
|                                       |
+=======================================+
|                                       |
|   🏠         🐾         💰        ⚙️  |
|   홈         케어      가계부     설정 |
|   ----                                |
|   (활성 탭: 파란 아이콘 + 밑줄)         |
|                                       |
+---------------------------------------+
   (safe area 여백)
```

**탭 구성:**

| 탭 | 아이콘 | 화면 | 역할 |
|----|--------|------|------|
| 홈 | 🏠 | 홈 대시보드 | 오늘 할 일 + 다가오는 일정 + 지출 요약 |
| 케어 | 🐾 | 케어 관리 | 항목 전체 목록 + 완료 + 추가/수정 |
| 가계부 | 💰 | 가계부 | 월별 통계 + 지출 내역 + 추가 |
| 설정 | ⚙️ | 설정 | 알림, 프로필, 반려동물 관리 |

**스타일:**
- 활성 탭: 아이콘 filled + `indigo-600` (#4F46E5) + 상단 2px 밑줄
- 비활성 탭: 아이콘 outline + `gray-400` (#9CA3AF)
- 배경: `white/95` + `backdrop-blur-lg` (콘텐츠 스크롤 시 반투명)
- 높이: 56px (터치 영역 44px 이상 보장)
- Safe area 하단 여백 적용 (iPhone notch/홈 인디케이터 대응)
- 탭 전환: 부드러운 페이드 트랜지션
