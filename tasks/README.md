# Task Files

`tasks/`는 현재 진행 중인 작업과 반복 방지용 운영 규칙을 관리하는 곳이다. 체크리스트 성격의 일감과 릴리즈 단위 진행 상황은 `todo.md`에 두고, 같은 문제를 다시 만들지 않기 위한 규칙은 `lessons.md`에 누적한다.

설계 설명이나 긴 배경 문서는 이 디렉터리에 두지 않는다. 그런 내용은 `docs/`로 보내고, `tasks/`에는 실행과 회고에 바로 필요한 내용만 남긴다. 작업이 끝난 뒤에도 장기간 참고 가치가 있는 운영 규칙만 유지하고, 소모성 메모는 루트가 아니라 `docs/archive/`로 정리한다.
